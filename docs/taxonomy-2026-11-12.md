# Taxonomy additions — 2026-11-12

User request: add basking sharks and fill missing families and orders. Version remains v5.6. Added 57 nodes: 40 families, 16 orders, and one genus. No existing taxa removed.

## Basking sharks and shark orders

- Selachii → Lamniformes → Cetorhinidae → Cetorhinus (basking sharks). [FishBase](https://www.fishbase.se/summary/Cetorhinus-maximus.html).
- Lamnidae now sits under Lamniformes. Otodus is under extinct Otodontidae, also under Lamniformes. GBIF returned an older Lamnidae placement for Otodus; the chart uses [Smithsonian specimen taxonomy](https://www.si.edu/object/nmnhpaleobiology_3424570) and the [peer-reviewed otodontid review](https://pmc.ncbi.nlm.nih.gov/articles/PMC5764036/).
- Carcharhinidae and Sphyrnidae → Carcharhiniformes; Rhincodontidae → Orectolobiformes.
- Rajidae → Rajiformes; Dasyatidae, Myliobatidae and Mobulidae → Myliobatiformes. Existing family names are preserved.

## Classification choices and scope

- The user specifically requested missing families and orders. This permits single-child family/order steps for these additions, superseding the earlier preference to omit them.
- Balanus uses Balanomorpha (order), following the [marine habitat classification](https://www.miteco.gob.es/content/dam/miteco/es/biodiversidad/temas/biodiversidad-marina/GUIA%20INTERP_HABITATS_WEB_tcm30-521436.pdf), rather than GBIF’s older Sessilia name.
- Branchiostoma uses Amphioxiformes, following [ITIS](https://www.itis.gov/servlet/SingleRpt/SingleRpt?search_topic=TSN&search_value=159681).
- Both living lungfish genera use Ceratodontiformes, consistent with current FishBase ([Protopterus](https://www.fishbase.se/summary/Protopterus-annectens)).
- Peripatus receives Peripatidae; no unsupported order is invented. Limulus retains the chart’s existing Xiphosura order convention.
- Existing hominid and whale ancestry chains are preserved. This pass fills family ancestry for all living genera currently in the chart; it is not a complete audit of all missing orders or extinct fossil families.
