# Combined family/genus entries — v6.0

Date: 2026-11-14. After the 21-animal batch was published successfully, the user requested removing unnecessary genus boxes that repeat the family’s animal name. They supplied Apteryx/Apterygidae, Dinornis/Dinornithidae, Rhea/Rheidae and Struthio/Struthionidae as examples, then explicitly chose similar repeated pairs across the whole chart. This authorizes the following specific removals under the project’s otherwise no-removal rule.

## Scope

Fifty leaf genera were removed from the plotted taxonomy. Each was the only displayed child of its family and repeated the same common animal label. The family stays in its original rank/color/position in the hierarchy. This is a visual simplification, not a claim that a family and genus have identical taxonomic scope: families can include other living or extinct genera. Pairs with distinct common labels or multiple displayed genera remain. This is an explicit reviewed list, not an automatic rule that removes every singleton genus. No new animals are added by this cleanup, so version v6.0 and counter 0/5 toward v6.1 remain unchanged.

## Search and saved content

Both charts redirect the former genus names, descriptions and existing search aliases to their retained families. The shared entry-groups.js lists both original scientific-name keys. Existing IndexedDB records are never renamed, merged, overwritten or deleted. If saved/published work exists for a former genus, the family’s information window shows Saved pages links; these open the original page with its original text/images/captions. Family and genus records are independently editable; switching honors existing unsaved-close confirmation. Backups retain all records, and restoring old genus records refreshes these links immediately. Read-only mode exposes published records only, preserving private browser drafts. A new cache URL loads the updated shared editor.

The v6.0 additions of Daubentonia, Heterocephalus, Balaeniceps, Sagittarius, Mitsukurina, Chlamydoselachus and Architeuthis are now represented by their retained family boxes; their names/common names remain searchable, and their saved pages are accessible as above. The original batch source notes remain a historical record.
