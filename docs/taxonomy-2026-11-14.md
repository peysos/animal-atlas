# Taxonomy additions — 2026-11-14

Batch release v5.8. Four requested genera added; the requested coelacanth was already present. Eight new chart nodes, from 983 to 991 taxa; no existing IDs or scientific titles renamed or removed.

| Added genus | Placement in the chart | Source |
|---|---|---|
| Elginia | Sauropsida → Parareptilia → Pareiasauridae → Elginia | [Natural History Museum specimen classification](https://data.nhm.ac.uk/dataset/collection-specimens/resource/05ff2255-c38a-40c9-b657-4ccb55ab2feb/record/5475210/dwc) |
| Hypsognathus | Sauropsida → Parareptilia → Procolophonidae → Hypsognathus | [Sues et al. (2000)](https://www.ldeo.columbia.edu/~polsen/nbcp/sues.olsen.etal.00.pdf) |
| Amargasaurus | Sauropoda → Dicraeosauridae → Amargasaurus | [Natural History Museum](https://www.nhm.ac.uk/discover/dino-directory/amargasaurus.html) |
| Dilophosaurus | Theropoda → Dilophosaurus | [Marsh and Rowe (2020)](https://www.jsg.utexas.edu/txvp/files/MarshandRowe2020.pdf) |

Hypsognattus, the spelling in the request, remains an alias for Hypsognathus. Coelacanths are represented by the existing Latimeria genus and Latimeriidae family under Coelacanthiformes. Both chart searches find Latimeria for coelacanth.

The chart retains its broad, conventional Parareptilia group and Pareiasauridae family usage, rather than restructuring existing reptile lineages. Some papers use Elginiidae as a more narrowly defined family for Elginia. Dilophosaurus is placed directly under Theropoda instead of creating a disputed Dilophosauridae family: Marsh and Rowe did not recover that family as monophyletic. Supporting ranks follow the user’s request to show families where supported; no unrelated taxa were added.

All new nodes are extinct and use their rank fills with red borders and daggers. The entry-content configuration, IndexedDB schema and existing scientific-name storage keys are preserved; image browsing changes only the displayed image index.
